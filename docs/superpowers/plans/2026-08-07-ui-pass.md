# UI-проход по четырём окнам — план внедрения

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ САБ-СКИЛЛ: `superpowers:subagent-driven-development`
> (рекомендуется) либо `superpowers:executing-plans`. Шаги помечены чекбоксами
> (`- [ ]`) для отслеживания.

**Цель:** привести четыре окна к одному визуальному языку — иерархия панели,
согласованность между окнами, контраст в обеих темах и оживление мёртвых
CSS-состояний — не меняя поведения таймера.

**Архитектура:** правки идут по шести корневым причинам из спеки, а не по
семидесяти пяти симптомам: одна правка гасит от трёх до десяти. Порядок задач
подчинён зависимостям — сначала токены (их используют все окна), потом панель,
потом три остальных окна, последней задачей перезапись эталонов сверки.

**Стек:** ванильный CSS без сборщика, Node.js built-in test runner (`node --test`),
Playwright для e2e, Electron 43.

**Спека:** `docs/superpowers/specs/2026-08-07-ui-pass-design.md`

## Глобальные ограничения

Требования проекта, действующие в КАЖДОЙ задаче. Нарушение любого из них —
основание отклонить задачу на ревью.

- **Перерасход всегда красный.** Оранжевый удалён намеренно и возвращать его нельзя.
- **Палитра статуса фиксирована:** идёт зелёный, пауза оранжевый, завершено
  красный статичный, перерасход красный пульсирующий. **Пульсация — единственное,
  что отличает два красных состояния.** Анимацию к `finished` не добавлять.
- **Инлайновые цвета сбрасываются пустой строкой** (`el.style.color = base || ''`),
  а не через `_baseTimerColor` без фолбэка: на чистом профиле `_baseTimerColor`
  не определён, и красный не снимался бы никогда.
- **Центрируются цифры, а не вся надпись со знаком минус.** Контейнер
  `width: fit-content; margin-inline: auto`, знак `position: absolute; right: 100%`,
  `font-size: 0.62em`, по вертикали по центру. Допуск e2e — 1.5px.
- **Разделитель флипа виджета — точки через `::before`/`::after`**, собственный
  текст `:` подавлен `font-size: 0`. Любой `font-size` на
  `.widget-flip-separator` возвращает глиф поверх точек.
- **Надстрочные секунды часов:** `width: 0; overflow: visible`, сдвиг только
  `transform`.
- **Виджет и часы — прозрачные окна** (`transparent: true`, `hasShadow: false`):
  никаких внешних теней (`box-shadow` без `inset`, `drop-shadow`, `filter: shadow`),
  только `inset` и `border`.
- **Виджет и полноэкранный дисплей не принимают светлую тему** — фон этих окон
  красит пользователь инлайново. Любой новый `var(--tw-…)` в этих файлах обязан
  быть прибит в их собственном блоке `[data-theme="light"]`, иначе
  `tests/contrast.test.js` справедливо упадёт: он берёт список токенов грепом
  по файлу.
- **Часы, наоборот, тему принимают** — своим фоном владеют они сами.
- **Кольцо в перерасходе невидимо по построению** (`strokeDashoffset === circumference`).
  Трек — отдельный элемент, он и должен быть виден.
- **Порядок `fonts.css → design-tokens.css → control.css` не меняется** —
  закреплён `tests/control-decomposition.test.js`.
- **`design-tokens.css` содержит токены, а не рецепты.** Классов туда не добавлять.
- **Никаких внешних URL, шрифтов и сетевых зависимостей** — CSP `font-src 'self' data:`.
- **Новый файл обязан попасть в `package.json` → `build.files`**, иначе он молча
  исчезнет из собранного приложения.
- **Не запускать `perl -pi` по этим файлам** — они UTF-8 с кириллицей, Perl
  читает байты как latin-1 и превращает весь файл в мохибейк. Только Edit или
  Python с явным `encoding='utf-8'`.
- **Source-level тесты режут комментарии** через `codeOnly()` из
  `tests/helpers/source-scan.js` перед проверками отсутствия — иначе assertion
  срабатывает на собственном объясняющем комментарии.
- Стиль кода: 2 пробела, одинарные кавычки, `eqeqeq`, `curly`.
