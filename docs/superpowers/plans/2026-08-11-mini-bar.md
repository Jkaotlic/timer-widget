# Свёрнутая панель — режим «полоса». План реализации

> **Для агентов:** используйте `superpowers:subagent-driven-development` или
> `superpowers:executing-plans`. Шаги помечены чекбоксами (`- [ ]`).

**Цель.** Свернуть окно управления в горизонтальную полосу `400 × 52` с точкой
состояния, временем, паузой/стартом/сбросом и шевроном разворота — чтобы после
настройки таймера панель занимала строку, а не пол-экрана, и при этом умела то,
чего не умеет виджет: паузу и сброс.

**Подход.** Полоса — не новое окно и не новая разметка таймера, а ВТОРОЕ
состояние того же окна: `<body class="collapsed">` плюс отдельный блок
`.mini-bar` в той же панели. Время и статус в него пишет тот же
`updateDisplay()`, что и в герой-блок, — иначе появится второй источник правды
о времени, а это ровно та ошибка, которую проект уже ловил в дисплее. Размер,
пол минимального размера и «поверх всех окон» меняет ГЛАВНЫЙ ПРОЦЕСС по одному
новому каналу: `minHeight: 660` задан при создании окна, и снять его из
рендерера нельзя.

**Стек.** Electron, ванильный JS без сборщика, `node --test`, Playwright.
Спека: `docs/superpowers/specs/2026-08-11-mini-bar-design.md`.

## Решения по открытым вопросам спеки

Оба закрыты ДО планирования, как спека и требовала.

1. **Якорь по вертикали — ВЕРХНИЙ КРАЙ.** Полоса встаёт туда, где был титлбар,
   и шеврон не убегает из-под курсора, который по нему только что кликнул.
   Правило проекта «держать ЦЕНТР при изменении размера» относится к
   Ctrl+колесу в виджете и часах, где содержимое растёт вокруг себя и курсор ни
   к чему не привязан; здесь источник — клик по конкретной кнопке вверху окна.
   Расхождение записывается комментарием в коде.
2. **Горячая клавиша — `M`.** Проверено ПО КОДУ, а не по памяти: в
   `electron-control.html` глобальный обработчик занимает `Space`, `KeyR`,
   `KeyS`, `KeyW`, `KeyC`, `KeyD`, `Digit1`–`Digit8`, `Escape`, `F1`; главный
   процесс перехватывает `Ctrl` + `=`/`+`/`-`/`0`. `KeyM`, `KeyB`, `KeyH`,
   `KeyZ` не заняты ни в одном из четырёх окон. Взято `M` («мини»), рядом с
   `W`/`C`/`D` по смыслу «переключить вид». Модификаторы не трогаются, поэтому
   системный `Cmd+M` (сворачивание в док) продолжает работать.

## Общие ограничения

- **Без сборщика.** Каждый файл — классический `<script>`; межмодульные ссылки
  идут через `window.X`. Голое имя ломает lint.
- **Новый модуль обязан попасть в `package.json` → `build.files`**, иначе он
  молча исчезнет из собранного приложения (`tests/packaging.test.js`).
- **Новый IPC-канал заводится в ЧЕТЫРЁХ местах:** `channel-validator.js`
  (whitelist), оба конца — отправитель и получатель (иначе падает
  `tests/ipc-liveness.test.js`: канал в списке — это разрешение, а не
  функция), и таблица каналов в `CLAUDE.md`.
- **Порядок таблиц стилей несущий:** `fonts.css → design-tokens.css →
  control.css`. Закреплён `tests/control-decomposition.test.js`.
- **Потолок `electron-control.html` — 2970 строк, потолок inline-скрипта
  отдельный и НЕ поднимается.** Сейчас файл занимает 2967 строк, то есть
  запаса три строки: **вся логика полосы живёт в отдельном модуле
  `mini-bar.js`**, в панели остаётся разметка и одна строка проводки. Это не
  пожелание — иначе задача просто не соберётся.
- **Цвет — переменная, состояние — класс, инлайн не используется.**
- **Полосы состояния считает `window.RendererShared.timerColorBand`** — тот же
  источник, что у виджета и дисплея. Своя лесенка порогов запрещена.
- **Тесты уровня исходника обязаны срезать комментарии** через
  `tests/helpers/source-scan.js` (`codeOnly()`).
- **Esc не трогаем.** В этом окне он уже слоёный (модалка → ящик → пикер).
- **`npm run ci` обязан быть зелёным перед каждым коммитом.**
- Порог мишени `--tw-hit-min: 32px`; контраст текста — AA 4.5:1 в тёмной теме и
  AAA 7:1 в светлой, нетекстовый индикатор — 3:1.

```js
// Свёрнутое состояние окна управления.
//
// Пол минимального размера (minHeight: 660) задан при создании окна, и снять
// его из рендерера нельзя — поэтому режим полосы живёт здесь. Порядок важен:
// сначала снять пол, потом сжимать, иначе setSize молча обрежется до 660.
//
// Верхний край держится намеренно: полоса встаёт туда, где был титлбар, и
// шеврон не убегает из-под курсора, который по нему кликнул. Правило проекта
// «держать ЦЕНТР» относится к Ctrl+колесу в виджете и часах, где содержимое
// растёт вокруг себя; здесь источник — клик по конкретной кнопке вверху.
let controlBoundsBeforeCollapse = null;

ipcMain.on('control-collapse', (_event, payload) => {
    if (!controlWindow || controlWindow.isDestroyed() || !payload || typeof payload !== 'object') { return; }
    const collapsed = payload.collapsed === true;
    const [curW] = controlWindow.getSize();

    if (collapsed) {
        // Высота приходит из рендерера (её знает CSS), но доверять ей нельзя:
        // это тот же непроверенный payload, что и во всех остальных
        // обработчиках размеров.
        const raw = Number.isFinite(payload.height) ? payload.height : 52;
        const barHeight = Math.max(36, Math.min(120, Math.round(raw)));

        controlBoundsBeforeCollapse = controlWindow.getBounds();
        const { x, y } = controlBoundsBeforeCollapse;
        controlWindow.setMinimumSize(CONFIG.CONTROL_WINDOW_MIN_WIDTH, 1);
        controlWindow.setSize(curW, barHeight);
        controlWindow.setPosition(x, y);   // держим ВЕРХНИЙ край
        controlWindow.setAlwaysOnTop(true);
        return;
    }

    // Разворот: пол возвращается ДО restore, иначе окно можно оставить
    // панелью высотой 52 — это обрезанная раскладка, которую чинила задача
    // про минимальную высоту.
    controlWindow.setMinimumSize(CONFIG.CONTROL_WINDOW_MIN_WIDTH, CONFIG.CONTROL_WINDOW_MIN_HEIGHT);
    controlWindow.setAlwaysOnTop(false);
    const prev = controlBoundsBeforeCollapse;
    if (prev) {
        controlWindow.setBounds(prev);
        controlBoundsBeforeCollapse = null;
    } else {
        controlWindow.setSize(curW, CONFIG.CONTROL_WINDOW_MIN_HEIGHT);
    }
});
```

Создать `mini-bar.js`:

```js
'use strict';

/**
 * Режим «полоса» окна управления.
 *
 * Панель после настройки нужна не как панель, а как индикатор с кнопкой
 * паузы, поэтому окно схлопывается в строку 400×52: точка состояния, время,
 * пауза/старт/сброс, шеврон разворота.
 *
 * Логика вынесена в отдельный файл не ради красоты: inline-скрипт
 * electron-control.html упирается в собственный потолок размера
 * (tests/control-decomposition.test.js), и держать её там нельзя. Зависимости
 * внедряются, поэтому модуль проверяется в Node на поддельных document/ipc —
 * так же устроен onboarding.js.
 *
 * Разметку и размеры модуль НЕ знает: он ставит класс на <body>, всё
 * остальное делает control.css. Размер окна меняет главный процесс — пол
 * minHeight снимается только там (см. канал control-collapse).
 */

// Высота полосы. Число живёт здесь, а CSS повторяет его в правиле
// `body.collapsed .mini-bar { height: 52px }` — расхождение поймает
// e2e/mini-bar.spec.js: он меряет НАСТОЯЩЕЕ окно, а не константу.
const BAR_HEIGHT = 52;

function init(deps) {
    const doc = deps && deps.doc;
    const ipc = (deps && deps.ipc) || null;
    const onToggle = (deps && deps.onToggle) || null;
    if (!doc || !doc.body) { return null; }

    let collapsed = false;

    const api = {
        isCollapsed: () => collapsed,
        collapse: () => setState(true),
        expand: () => setState(false),
        toggle: () => setState(!collapsed)
    };

    function setState(next) {
        if (next === collapsed) { return api; }   // без дребезга
        collapsed = next;
        if (onToggle) { onToggle(collapsed); }
        if (collapsed) {
            doc.body.classList.add('collapsed');
        } else {
            doc.body.classList.remove('collapsed');
        }
        syncAria();
        if (ipc && typeof ipc.send === 'function') {
            ipc.send('control-collapse', collapsed
                ? { collapsed: true, height: BAR_HEIGHT }
                : { collapsed: false });
        }
        return api;
    }

    function syncAria() {
        const btn = doc.getElementById('miniBarToggle');
        if (btn && btn.setAttribute) { btn.setAttribute('aria-expanded', collapsed ? 'false' : 'true'); }
    }

    for (const id of ['miniBarToggle', 'miniBarExpand']) {
        const el = doc.getElementById(id);
        if (el && el.addEventListener) { el.addEventListener('click', () => api.toggle()); }
    }
    syncAria();

    return api;
}
```
